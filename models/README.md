# Модели

Веса нейросетей не публикуются в этом репозитории.

Для ноутбучного детектора положите совместимый YOLO checkpoint, например
`rtk-best.pt`, в эту папку и запустите:

```bash
python3 tools/object_detector.py --model models/rtk-best.pt
```

Финальная модель соревнования использовала три класса:

| ID | Имя класса | Объект |
|---:|---|---|
| 0 | `rtk-benzovoz` | бензовоз |
| 1 | `rtk-derevo` | дерево |
| 2 | `rtk-dtp` | ДТП |
| 3 | `rtk-qr` | область QR (опционально) |

QR-коды распознаются отдельным классическим конвейером и не зависят от YOLO.
