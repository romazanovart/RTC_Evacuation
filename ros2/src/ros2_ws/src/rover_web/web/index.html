Маршрут по карте: A → B → C

Выбери карту, запусти Nav2 и нажимай на карту, чтобы добавить точки. Робот выполнит их по порядку.

Готово к настройке
Клик добавляет следующую точку. Координаты и курс можно исправить справа.
Нажми на карту: первая точка будет A.
